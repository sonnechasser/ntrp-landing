Five vitals. Not another CRM.
NTRP runs on your machine. Score Freshness, Flow, Drop, Signal:Noise, and Thread Depth — then ask what to do next. Free on npm. First run asks for your AI key so chat can work.
Install
npm i -g @sonnechasser/ntrp@2.5.0

What you get
────────────────────────────────────────────────────────
1. Install
One npm command. No signup. No license key. No checkout.
2. Add your AI key
First run asks for a provider key so chat and analysis can run. That is not a payment step.
3. Point at pipeline data
Drop local exports. Data stays on this machine. Ask: how healthy is the pipeline? what should I do next?
Five vitals
────────────────────────────────────────────────────────
Read in order: Freshness (is the number true?) → Flow + Drop (stuck / handoff) → Signal + Thread (busywork / thin deals).
Freshnessis the pipeline number still true
Flowhow fast deals move through stages
Drophow many qualified leads survive handoff
Signal:Noisehow much activity is real pipeline work
Thread Depthcontacts per deal — one leaves, deal dies
